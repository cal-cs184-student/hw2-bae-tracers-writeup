Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

What is the de Casteljau's algorithm?

De Casteljau's algorithm is a method of evaluating Beizer curves by recursively dividing length in relation to a constant t by (t)(i) + (1-t)(i). This t is then sampled multiple times to form a curve which is the Beizer curve.

Part 2: Bezier surfaces with separable 1D de Casteljau

How de Casteljau algorithm extends to Bezier surfaces

Given N * N Bezier Points as specified by a designer, de Casteljau's algorithm, which is used to find a Bezier curve can be extended to bezier surfaces by running the algorithm each row and evaluating t=u, and using the results of the evaluation by running the same algorithm with the outputs of each row on t = v.

Part 6: Loop subdivision for mesh upsampling

How you implemented the loop subdivision

I implemented loop subdivision by following the rules of the spec, i first iterated around the verticies and added its neighbors based off the formula
(1 - n * u) * original_position + u * original_neighbor_position_sum
where u depends on if n=3 or not. I then found the new verticies location with 3/8 * (A + B) + 1/8 * (C + D), split the verticies, and then used the isNew tag to find a halfedge where one is new and old (the one that needs flipping), and then i updated the old positions.
